# Slide Generator
Automatic generation of powerpoint presentations from templates using python-pptx.

One thing to note is that hymns-copy.sqlite is not up to date and probably contains mistakes. It's purpose is to emulate the structure of the database that will be used in the future.

This generator supports the following in the template:
- Text
- Images
- Charts
- Maybe Tables

It definitely does not support videos or audio or any other complex objects.
